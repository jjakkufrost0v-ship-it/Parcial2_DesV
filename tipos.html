Tipos de APIs

Conoce algunas formas de clasificar las interfaces de programación de aplicaciones.

Según su acceso

Las APIs se pueden clasificar de acuerdo con quién tiene permiso para utilizarlas.

APIs públicas

Están disponibles para desarrolladores externos bajo las condiciones de acceso y uso definidas por su proveedor.

APIs privadas

Se utilizan para comunicar sistemas internos de una organización y normalmente tienen acceso restringido.

APIs para socios

Se comparten con socios o colaboradores autorizados mediante acuerdos y permisos específicos.

Según su estilo o tecnología

Existen diferentes formas de diseñar y construir APIs.

01

REST

Estilo arquitectónico para servicios web que utilizan recursos y operaciones HTTP.

02

SOAP

Protocolo de intercambio de mensajes estructurados que puede utilizarse en servicios web.

03

GraphQL

Lenguaje de consulta y entorno de ejecución para APIs que permite solicitar los campos de datos necesarios.
